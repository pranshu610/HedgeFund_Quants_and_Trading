# Quant Finance Encyclopedia & Calculator

A reference and calculator I use alongside my degree and CFA study.

## Sections
- Greek alphabet and notation
- Technical indicators and the Ichimoku system
- Options and the Greeks
- Risk and performance metrics
- Quant formulas
- Fundamental analysis
- Finance concepts

## Calculators
Position size and risk, Kelly criterion, risk-reward to breakeven win rate, CAGR and compound growth, bond duration and price, Sharpe and Sortino from a return series, a quick DCF, and FX pip value.

## Run it
```bash
pip install streamlit pandas numpy plotly scipy
streamlit run app.py
```
